## Bug Fixes Applied (v2.3 Optimized)

### Critical Fixes

1. **Boundary Marker Typo** (FIXED)
   - Issue: Validation used [7031, 1223, 29515] instead of [7031, 1233, 29515]
   - Impact: Caused fallback to midpoint boundary in validation, misaligning signal
   - Solution: Module-level constant `PASSAGE_MARKER = [7031, 1233, 29515]`

2. **Tokenizer Mismatch** (FIXED)
   - Issue: Model loaded from unsloth but tokenizer from mistralai
   - Impact: Potential token ID mismatches between train and eval
   - Solution: Consistent tokenizer: `AutoTokenizer.from_pretrained("unsloth/mistral-7b-instruct-v0.3-bnb-4bit")`

3. **Code Duplication** (FIXED)
   - Issue: Boundary detection duplicated in 3 locations (compute_token_scores, evaluate_validation_set, compute_passage_scores_batch)
   - Impact: Typo in one location easy to miss; future changes could be incomplete
   - Solution: Dedicated `find_query_end()` helper function with single source of truth

4. **Multiprocessing Pickle Error** (FIXED)
   - Issue: Python 3.14 requires picklable collate_fn (lambda not allowed)
   - Solution: Named `identity_collate()` function + `num_workers=0`

5. **Architecture Mismatch** (FIXED)
   - Issue: Script expected ImportanceUpdateHead but initialized wrong type
   - Solution: Proper QueryAwareImportanceHead initialization matching proven patterns
