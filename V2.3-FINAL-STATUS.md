### 1. Boundary Marker Typo ✅
- **Issue:** Validation used wrong token [1223 vs 1233]
- **Impact:** All validations fell back to midpoint
- **Fix:** `PASSAGE_MARKER = [7031, 1233, 29515]` (line 57)

### 2. Tokenizer Mismatch ✅
- **Issue:** Model ≠ Tokenizer source (unsloth vs mistralai)
- **Impact:** Potential token ID mismatches
- **Fix:** Consistent source: `unsloth/mistral-7b-instruct-v0.3-bnb-4bit` (line 465)

### 3. Code Duplication ✅
- **Issue:** Boundary detection duplicated in 3 places with typo in one
- **Impact:** Maintenance risk, typo propagation
- **Fix:** Dedicated `find_query_end()` helper (single source of truth)

### 4. Multiprocessing Error ✅
- **Issue:** Python 3.14 lambda not picklable
- **Impact:** `_pickle.PicklingError` at launch
- **Fix:** Named `identity_collate()` function + `num_workers=0`

### 5. Architecture Mismatch ✅
- **Issue:** ImportanceUpdateHead vs QueryAwareImportanceHead signature mismatch
- **Impact:** `TypeError: unexpected keyword argument 'doc_hidden'`
- **Fix:** Proper QueryAwareImportanceHead init (lines 450-493)
