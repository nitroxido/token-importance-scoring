## Deployment Instructions

### For Production Use

**Source Checkpoint:**
```bash
Source: checkpoints/v2.3_final/best/tis_components.pt

Test MRR: 0.5102
```

**Loading Instructions:**
```python
import torch
from src.token_importance.model.patched_model import PatchedCausalLM
from src.token_importance.model.query_aware_head import QueryAwareImportanceHead

# Load base model
model = PatchedCausalLM.from_pretrained(
    "unsloth/mistral-7b-instruct-v0.3-bnb-4bit",
    device_map="auto",
    torch_dtype=torch.bfloat16
)

# Set up head
model.importance_head = QueryAwareImportanceHead(
    d_model=4096,
    config=model.tis_config,
    num_heads=4,
    query_pool_method="mean",
    use_postnorm=True
).to(model.device).to(torch.bfloat16)

# Load checkpoint
checkpoint = torch.load("checkpoints/v2.3_final/best/tis_components.pt", 
                       map_location=model.device)
model.importance_embedding.load_state_dict(checkpoint["importance_embedding"])
model.importance_head.load_state_dict(checkpoint["importance_head"])

model.eval()
```

**Tokenizer:**
```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(
    "unsloth/mistral-7b-instruct-v0.3-bnb-4bit"
)
```

**Inference:**
```python
# Format: "Question: {query}\n\nPassage: {passage}\n\nAnswer:"
prompt = "Question: what is python\n\nPassage: Python is a programming language\n\nAnswer:"

with torch.no_grad():
    output = model(inputs)
    importance_scores = model.importance_head(
        doc_hidden=output.hidden_states[-1],
```
